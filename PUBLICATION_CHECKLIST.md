# Publication checklist

- [ ] Confirm organization permits publication of tool and its source
- [ ] Confirm copyright ownership and permitted licensing of generated code
- [ ] Choose OSI-approved license (e.g. MIT if authorized) and commit LICENSE
- [ ] Review code for secrets, infrastructure details, diagnostics and privacy risk
- [ ] Test Windows x64 GUI, Crop, Undo, mask/redaction, Clipboard, ZIP, DPI scaling
- [x] Remove raw screenshot diagnostic capture and on-disk diagnostics from source (desktop verification pending)
- [ ] Verify third-party artwork/branding rights and add only cleared assets
- [ ] Create public GitHub repository with MFA and appropriate review permissions
- [ ] Publish documented unsigned pre-release and disclose Smart App Control limitations
- [ ] Maintain a public release and respond to reports before applying to SignPath
- [ ] Submit SignPath Foundation application with repository and release URLs
- [ ] Only after approval: configure origin verification and signing in CI
