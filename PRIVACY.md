# Privacy Policy

**ScrollScreen**

**Maintainer:** usermister  
**Last updated:** November 13, 2026

## 1. Overview

ScrollScreen is a free, open-source Windows application for capturing, stitching, editing, and redacting screenshots.

The project is maintained by usermister and developed with AI assistance.

## 2. Screenshot Processing

ScrollScreen is designed to process screenshots locally on the user's Windows computer.

Captured images may contain personal, confidential, or sensitive information. Users are responsible for reviewing screenshots before sharing or exporting them.

## 3. Data Storage

Users can save screenshots and exported files to their computer.

The application may use temporary data during screenshot capture and processing. Users should protect exported files and clipboard contents appropriately.

## 4. Data Collection and Network Communication

The current project design does not require user accounts, cloud storage, or a remote screenshot-processing service.

Network behavior and third-party dependencies should be reviewed before each public release. Any future collection or transmission of user data will be documented in this policy.

## 5. Security

ScrollScreen provides image redaction functionality to help users conceal sensitive information.

Users should verify that confidential information is properly removed before sharing exported screenshots.

## 6. Open Source

The source code is publicly available at:

https://github.com/usermister/ScrollScreen-OpenSource

## 7. Contact

For privacy questions or security concerns, please open an issue in the project's GitHub repository. Do not include sensitive screenshots, passwords, or personal information in public issues.
